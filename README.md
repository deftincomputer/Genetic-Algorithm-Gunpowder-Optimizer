# Genetic-Algorithm-Gunpowder-Optimizer
**Finding the optimal combination of gunpowder to produce more energy using a genetic algorithm.**

**This code uses a genetic algorithm to find the best combination of charcoal, sulfur, and potassium nitrate to produce gunpowder with the highest energy and explosive power. The values for **population_size** and **generations** can be defined for this algorithm. The only challenge is finding the right formula.**
